## What this does to the headline gap

| comparison at the top rung | AUROC | AUPRC |
|---|---|---|
| A features minus C (headline, 200 tokens) | +0.0216 | +0.0116 |
| A features minus C (512 tokens) | +0.0184 | +0.0076 |
| share of the gap explained by truncation | 15% | 35% |

- Longer context helps the Transformer, and helps it **more on AUPRC than on AUROC**, which is exactly the signature expected if the binding problem was censoring of the positive class. The effect is real and should be reported.
- It nonetheless closes only part of the gap. Engineered features still lead at the top rung with the censoring largely removed, so the headline is **not** an artefact of truncation.
- The top-rung 512 run is a single seed and is reported as a spot check.

## Capacity x data interaction

The question a fixed-capacity ladder cannot answer is whether extra capacity pays off *more* when there is more data. It does not:

| rung | d128/L2 (headline) | d128/L4 | delta |
|---|---|---|---|
| 300,000 | 0.7822 | 0.7817 | -0.0005 |
| 1,114,144 | 0.8063 | 0.8012 | -0.0050 |

- Doubling depth is neutral at 300k and **negative at the top rung**: the interaction runs the wrong way for a capacity explanation. Tripling parameters (d192/L4) does not help either.
- Larger models also early-stop **sooner** (mean best epoch 1.7 for d192/L4 at 300k against 3.7 for the headline), under a training budget that was fixed for all configurations. So the honest claim is that **capacity is not the binding constraint under a matched budget**, not that capacity can never help. Together with the seed-ensembling result, the evidence points at optimisation budget and data rather than model size.

## Bottom line for the paper

Both of the design choices most likely to be attacked were tested, and neither overturns the result. The context asymmetry is real but partial; the capacity objection is answered by a measured interaction rather than an argument. These are reported in the main text as pre-emptive checks, not buried as limitations.
